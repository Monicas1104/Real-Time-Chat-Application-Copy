Real-Time Chat Application

Overview

A real-time chat application developed using HTML, CSS, JavaScript, Node.js and Socket.IO. The application enables users to exchange messages through a client-server architecture.

Features

Real-time message sending and receiving.

Username identification.

Interactive chat interface.

Client-server communication using Socket.IO.

Event-driven message handling.

Dynamic message display.

Technologies Used

HTML

CSS

JavaScript

Node.js

Socket.IO

How to Run

Clone this repository:

git clone YOUR_REPOSITORY_URL

Navigate to the server folder:

cd server

Install dependencies:

npm install

Start the server:

node index.js

Open the client index.html file in your browser and connect to the running server.
